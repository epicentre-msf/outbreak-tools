Resolve #

Resolve a header key to its translation, remembering the answer.

Signature:

Public Function Resolve(ByVal key As String, ByVal fallback As String) As String

A key found in the table is answered from the cache from then on. A key the table does not carry answers the supplied fallback and stays uncached, so it can pick the translation up if the table gains it later.

Parameters:

  • key: String tag to translate.
  • fallback: String answered when the table does not carry the key.

Returns: String translated label, or the fallback.

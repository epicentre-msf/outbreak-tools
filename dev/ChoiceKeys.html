ChoiceKeys

The one place the export side and the import side build the name a custom dropdown is written under on a Choices sheet. Both ends call the same function, so the round trip can only agree.

THE NAME THE KEY IS BUILT FROM

The dropdown name held in the DropdownLists registry, exactly as the user typed it. Nothing is trimmed, nothing is sanitised and no counter is added. DropdownLists.AllDropdowns answers that list and DropdownLists.Update takes that same name, so a key built this way survives the trip in both directions.

WHY THE CLASS EXISTS

The two ends used to build the key from two different places. The export read the header cell of the ListObject, which holds the name with every space turned into an underscore; the import read the ListObject name and cut five characters off the front, which left the workbook counter on the end. So a dropdown called contact type was written as __choice_custom_contact_type and looked for as __choice_custom_contact type7. The lookup missed every time and importing a custom dropdown did nothing at all, in every case, for as long as the feature existed.

CustomChoiceName #

custom-choice-name

The Choices sheet key of a custom dropdown

Signature:

Public Function CustomChoiceName(ByVal listName As String) As String

An empty dropdown name answers an empty key. LLChoices.Categories reads an empty criteria as "blank cells" rather than as "nothing", so handing it a bare prefix would answer rows that belong to no dropdown.

Parameters:

  • listName: String. The dropdown name held in the DropdownLists registry.

Returns: String. The key the choice is stored under, empty when the name is empty.

ListNameFromChoice #

list-name-from-choice

The dropdown name a Choices sheet key was built from

Signature:

Public Function ListNameFromChoice(ByVal choiceName As String) As String

The inverse of CustomChoiceName. A key that carries no custom prefix answers an empty string, so a reader walking a whole Choices sheet can tell the custom dropdowns apart from the choices the setup file authored.

Parameters:

  • choiceName: String. A key read off a Choices sheet.

Returns: String. The dropdown name, empty when the key is not a custom one.
